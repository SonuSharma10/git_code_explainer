About Repo Explainer

AI-powered codebase intelligence for developers.

Repo Explainer is designed strictly for educational and learning purposes. It assists engineers, students, and open-source contributors in understanding large unfamiliar codebases, deciphering complex logic flows, and exploring architecture patterns with Google Gemini AI.

Key capabilities include interactive Mermaid architecture flowcharts, real-time API understanding, file-level deep dives, and collaborative issue debugging.

🔒 All personal Gemini API keys are encrypted at rest using Fernet symmetric encryption and never shared.
